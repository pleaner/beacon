# On call Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put one operator on shift at a time, send each overdue and help alert to them first, pass it down the roster when nobody answers or someone rejects, and keep a full record of every call, on the web board and in the Android app.

**Architecture:** Two new server modules. `src/lib/oncall.ts` owns the roster, availability, shift arithmetic and the shift-start push. `src/lib/calls.ts` owns calls: raising one, escalating it, accept and reject, the record, and who hears chat. The existing one-minute cron and the existing trip routes call into them. Everything the web pages show comes from the same functions the JSON API returns, so Android renders server-built lines and holds no logic of its own.

**Tech Stack:** Hono on Cloudflare Workers, D1 (SQLite), hono/jsx server views, vitest with `@cloudflare/vitest-plugin`, Kotlin and Jetpack Compose for Android.

**Spec:** `docs/superpowers/specs/2026-10-18-on-call-design.md`

## Global Constraints

- No new Cloudflare products and no new npm or Gradle dependencies. Timing comes from the existing one-minute cron in `src/lib/cron.ts`.
- Settings live in the `settings` key/value table through `getSetting`/`setSetting`. Defaults: `shift_hours` 8, `no_response_minutes` 2.
- Shifts are anchored to 06:00 Africa/Johannesburg (04:00 UTC). With 8 hours that's 06:00, 14:00 and 22:00. Shift length must divide 24 (1, 2, 3, 4, 6, 8, 12 or 24 hours) so every day starts at 06:00.
- The words on the buttons are exactly "Accept" and "Reject".
- Anti-goal: an alert that reaches nobody. Every path that can't find an on-call person pushes to all operators and admins, as today.
- Pushes go through `src/lib/push.ts` (`pushToUser`, `pushToSubs`). No action buttons on notifications. The alert opens the trip page.
- Roster changes and availability changes never go on a call record. Individual GPS fixes stay off the record.
- First accept wins, enforced by a conditional `UPDATE` in the database.
- Copy follows the repo's voice: plain sentences, no em dashes.
- Tests: `npm test` (vitest, Workers pool). Every task ends with `npm run typecheck && npm test` green. Android tasks end with `JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew assembleDebug` green from `android/`.

## Review Focus

- Two operators press Accept at the same moment: exactly one wins and the other gets "Someone else accepted this call first." Test in Task 2 (`accept race`).
- The person on shift has no working device: they're passed over in the same run, the record says so, and if nobody on the roster has a device the call goes to everyone. Tests in Task 2 (`no device`, `no one on the roster can receive`).
- The trip ends while a call is waiting to escalate: the next cron run sends nothing more. Test in Task 3 (`back safe stops escalation`).
- A roster member is made an explorer or deleted: they drop off the roster and out of escalation without anyone touching the list. Test in Task 1 (`role and delete`).
- An admin changes the shift length mid-shift, or the stored value is junk: the shift is recomputed, and a junk value falls back to 8 hours. Tests in Task 1 (`junk shift_hours`) and Task 4 (`settings save`).

```sql
-- On call: a roster that takes turns in fixed shifts, and a record of each overdue or help call.
CREATE TABLE oncall (
  user_id TEXT PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  sort INTEGER NOT NULL,
  available INTEGER NOT NULL DEFAULT 1
);

-- One call per overdue alert or help request. next_at is when it passes on if nobody answers; NULL once it has
-- stopped escalating (accepted, sent to everyone, closed, or waiting for the cron to raise it again).
CREATE TABLE calls (
  id TEXT PRIMARY KEY,
  trip_id TEXT NOT NULL REFERENCES trips(id) ON DELETE CASCADE,
  kind TEXT NOT NULL CHECK (kind IN ('overdue','help')),
  started_at INTEGER NOT NULL,
  next_at INTEGER,
  everyone_at INTEGER,
  accepted_by TEXT REFERENCES users(id) ON DELETE SET NULL,
  accepted_at INTEGER,
  closed_at INTEGER
);
CREATE UNIQUE INDEX calls_open ON calls(trip_id, kind) WHERE closed_at IS NULL;

-- Everyone a call has reached. They keep it as it escalates, unless they rejected it.
CREATE TABLE call_targets (
  call_id TEXT NOT NULL REFERENCES calls(id) ON DELETE CASCADE,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  alerted_at INTEGER NOT NULL,
  rejected_at INTEGER,
  PRIMARY KEY (call_id, user_id)
);

-- The call record. Chat messages are read from messages, not copied here.
CREATE TABLE call_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  call_id TEXT NOT NULL REFERENCES calls(id) ON DELETE CASCADE,
  at INTEGER NOT NULL,
  kind TEXT NOT NULL,
  user_id TEXT REFERENCES users(id) ON DELETE SET NULL,
  detail TEXT
);
CREATE INDEX call_events_call ON call_events(call_id, id);

-- oncall_now is who was last told their shift began. syncShift updates it conditionally, so the row must exist.
INSERT OR IGNORE INTO settings (key, value) VALUES ('shift_hours', '8'), ('no_response_minutes', '2'), ('oncall_now', '');
```

```ts
import { getSetting, type User } from './db'
import { pushToUser, type PushSender } from './push'

type DB = D1Database

// Shift lengths that divide a day, so every day's first shift starts at 06:00 South African time.
export const SHIFT_HOURS = [1, 2, 3, 4, 6, 8, 12, 24] as const
// 2026-01-01 06:00 in Johannesburg (UTC+2, no daylight saving). Slots are counted from here.
const ANCHOR = Date.UTC(2026, 0, 1, 4)
const HOUR = 3_600_000

export interface RosterEntry {
  user_id: string
  name: string
  sort: number
  available: number
  // Push subscriptions on file. Zero means alerts can't reach them; the page warns.
  devices: number
}

// Only operators and admins count, so someone made an explorer drops off without anyone editing the list.
export async function listRoster(db: DB): Promise<RosterEntry[]> {
  return (
    await db
      .prepare(
        `SELECT o.user_id, u.name, o.sort, o.available,
           (SELECT COUNT(*) FROM push_subscriptions s WHERE s.user_id = o.user_id) AS devices
         FROM oncall o JOIN users u ON u.id = o.user_id
         WHERE u.role IN ('operator','admin') ORDER BY o.sort, o.user_id`,
      )
      .all<RosterEntry>()
  ).results
}

export async function addToRoster(db: DB, userId: string): Promise<boolean> {
  const r = await db.prepare('INSERT OR IGNORE INTO oncall (user_id, sort) SELECT ?, COALESCE(MAX(sort), 0) + 1 FROM oncall').bind(userId).run()
  return r.meta.changes > 0
}

export async function removeFromRoster(db: DB, userId: string): Promise<boolean> {
  return (await db.prepare('DELETE FROM oncall WHERE user_id = ?').bind(userId).run()).meta.changes > 0
}

// Swaps with the neighbour above (-1) or below (1), then renumbers the whole list 1..n.
export async function moveInRoster(db: DB, userId: string, dir: -1 | 1): Promise<boolean> {
  const ids = (await listRoster(db)).map((r) => r.user_id)
  const i = ids.indexOf(userId)
  const j = i + dir
  if (i < 0 || j < 0 || j >= ids.length) return false
  ;[ids[i], ids[j]] = [ids[j]!, ids[i]!]
  const stmt = db.prepare('UPDATE oncall SET sort = ? WHERE user_id = ?')
  await db.batch(ids.map((id, n) => stmt.bind(n + 1, id)))
  return true
}

export async function setAvailable(db: DB, userId: string, available: boolean): Promise<boolean> {
  return (await db.prepare('UPDATE oncall SET available = ? WHERE user_id = ?').bind(available ? 1 : 0, userId).run()).meta.changes > 0
}

async function settings(db: DB) {
  const [h, m] = await Promise.all([getSetting(db, 'shift_hours', '8'), getSetting(db, 'no_response_minutes', '2')])
  const hours = Number(h)
  const minutes = Number(m)
  return {
    shiftHours: (SHIFT_HOURS as readonly number[]).includes(hours) ? hours : 8,
    noResponseMs: (Number.isInteger(minutes) && minutes > 0 ? minutes : 2) * 60_000,
  }
}

export const slotAt = (now: number, hours: number) => Math.floor((now - ANCHOR) / (hours * HOUR))
export const slotStart = (slot: number, hours: number) => ANCHOR + slot * hours * HOUR

// Slot n belongs to the nth person in the cycle. If they're unavailable, the next available person after them
// takes it, so skipping someone never moves anyone else's slots.
export function ownerOf(roster: RosterEntry[], slot: number): RosterEntry | null {
  const n = roster.length
  if (n === 0) return null
  const start = ((slot % n) + n) % n
  for (let i = 0; i < n; i++) {
    const r = roster[(start + i) % n]!
    if (r.available) return r
  }
  return null
}

// Who a call goes to, in turn: the person on shift, then on down the list and round, available people only.
export function escalationOrder(roster: RosterEntry[], firstId: string | null): RosterEntry[] {
  const avail = roster.filter((r) => r.available)
  const i = avail.findIndex((r) => r.user_id === firstId)
  return i < 0 ? avail : [...avail.slice(i), ...avail.slice(0, i)]
}

export interface Shift {
  onNow: RosterEntry | null
  // When someone else takes over; null when nobody else is available.
  until: number | null
  next: RosterEntry | null
  roster: RosterEntry[]
  shiftHours: number
  noResponseMs: number
}

export async function currentShift(db: DB, now: number): Promise<Shift> {
  const [roster, s] = await Promise.all([listRoster(db), settings(db)])
  const slot = slotAt(now, s.shiftHours)
  const onNow = ownerOf(roster, slot)
  let until: number | null = null
  let next: RosterEntry | null = null
  // Owners repeat every roster.length slots, so one cycle ahead is far enough to look.
  for (let k = 1; onNow && k <= roster.length; k++) {
    const o = ownerOf(roster, slot + k)
    if (o && o.user_id !== onNow.user_id) {
      until = slotStart(slot + k, s.shiftHours)
      next = o
      break
    }
  }
  return { onNow, until, next, roster, ...s }
}

export async function isOnCall(db: DB, userId: string, now: number): Promise<boolean> {
  return (await currentShift(db, now)).onNow?.user_id === userId
}

// Tells whoever has just gone on shift, by the clock or by a handover. The cron runs it every minute, and the
// roster routes run it straight after a change. Returns true when someone new went on.
export async function syncShift(db: DB, send: PushSender, now: number): Promise<boolean> {
  const { onNow } = await currentShift(db, now)
  const id = onNow?.user_id ?? ''
  const prev = await getSetting(db, 'oncall_now', '')
  if (id === prev) return false
  // Conditional, so the cron and a roster change in the same moment don't both send it.
  const won = await db.prepare("UPDATE settings SET value = ? WHERE key = 'oncall_now' AND value = ?").bind(id, prev).run()
  if (won.meta.changes === 0 || !onNow) return false
  await pushToUser(db, send, onNow.user_id, {
    title: "You're on call",
    body: 'Your shift has begun. Overdue and help alerts come to you first.',
    url: '/board/oncall',
    tag: 'oncall',
    kind: 'shift',
  })
  return true
}

const person = (r: RosterEntry | null) => (r ? { user_id: r.user_id, name: r.name } : null)

// Everything the On call page and the app's On call screen show.
export async function onCallState(db: DB, viewer: Pick<User, 'id' | 'role'>, now: number) {
  const s = await currentShift(db, now)
  const mine = s.roster.find((r) => r.user_id === viewer.id)
  const candidates = viewer.role === 'admin'
    ? (
        await db
          .prepare(`SELECT id AS user_id, name FROM users WHERE role IN ('operator','admin') AND id NOT IN (SELECT user_id FROM oncall) ORDER BY name`)
          .all<{ user_id: string; name: string }>()
      ).results
    : []
  return {
    on_now: person(s.onNow),
    until: s.until,
    next: person(s.next),
    shift_hours: s.shiftHours,
    no_response_minutes: s.noResponseMs / 60_000,
    roster: s.roster.map((r) => ({ user_id: r.user_id, name: r.name, available: !!r.available, devices: r.devices, on_now: r.user_id === s.onNow?.user_id })),
    me: { on_roster: !!mine, available: !!mine?.available, on_call: !!mine && s.onNow?.user_id === viewer.id },
    candidates,
  }
}
export type OnCallState = Awaited<ReturnType<typeof onCallState>>
```

```ts
  user_id: string
  name: string | null

  rejected_at: number | null

export type CallEvent =

  | 'extended' | 'help' | 'help_cancelled' | 'back' | 'siren' | 'closed_trip' | 'admin_status' | 'closed'

export function formatTime(ms: number): string {
  return new Date(ms).toLocaleTimeString('en-ZA', { hour: '2-digit', minute: '2-digit', timeZone: 'Africa/Johannesburg' })
}

async function addEvent(db: DB, callId: string, at: number, kind: CallEvent, userId: string | null = null, detail: string | null = null) {
  await db.prepare('INSERT INTO call_events (call_id, at, kind, user_id, detail) VALUES (?,?,?,?,?)').bind(callId, at, kind, userId, detail).run()
}

export function getCall(db: DB, id: string) {
  return db.prepare('SELECT * FROM calls WHERE id = ?').bind(id).first<Call>()
}
async function listOpenCalls(db: DB, tripId: string): Promise<Call[]> {
  return (await db.prepare('SELECT * FROM calls WHERE trip_id = ? AND closed_at IS NULL').bind(tripId).all<Call>()).results
}
async function listTargets(db: DB, callId: string): Promise<CallTarget[]> {
  return (
    await db
      .prepare(
        `SELECT t.user_id, u.name, t.alerted_at, t.rejected_at FROM call_targets t LEFT JOIN users u ON u.id = t.user_id
         WHERE t.call_id = ? ORDER BY t.alerted_at, t.rowid`,
      )
      .bind(callId)
      .all<CallTarget>()
  ).results
}
async function stillOpen(db: DB, id: string): Promise<boolean> {
  const c = await getCall(db, id)
  return !!c && c.closed_at == null && c.accepted_at == null
}

// What an operator's phone shows for this call. Null when the trip or explorer is gone.
async function callPayload(db: DB, call: Call): Promise<PushPayload | null> {
  const trip = await getTrip(db, call.trip_id)
  const user = trip && (await getUserById(db, trip.user_id))
  if (!trip || !user) return null
  if (call.kind === 'help') return helpPayload(user, trip)
  const grace = await getSetting(db, 'grace_minutes', '30')
  return {
    title: `Overdue: ${user.name}`,
    body: `${tripLine(trip)}, due ${formatTime(trip.return_by)}. No answer for ${grace} min.`,
    url: `/board/trips/${trip.id}`,
    tag: `trip-${trip.id}`,
    kind: 'overdue',
  }
}

// Starts the trip's call of this kind, or finds the one already open, and sends it on.
export async function raiseCall(db: DB, send: PushSender, tripId: string, kind: CallKind, now: number) {
  const id = crypto.randomUUID()
  const ins = await db
    .prepare('INSERT OR IGNORE INTO calls (id, trip_id, kind, started_at, next_at) VALUES (?,?,?,?,?)')
    .bind(id, tripId, kind, now, now)
    .run()
  if (ins.meta.changes > 0) await addEvent(db, id, now, 'started', null, kind)
  const call = await db.prepare('SELECT * FROM calls WHERE trip_id = ? AND kind = ? AND closed_at IS NULL').bind(tripId, kind).first<Call>()
  if (!call) return { sent: 0, accepted: false }
  return { sent: await advance(db, send, call, now), accepted: call.accepted_at != null }
}

// Sends the call to the next person in turn who hasn't had it. Someone with no working device is passed over in
// the same run. When the turns run out, or nobody is on call, it goes to every operator and admin who hasn't
// rejected it. Returns how many devices it reached.
export async function advance(db: DB, send: PushSender, call: Call, now: number): Promise<number> {
  if (call.closed_at != null || call.accepted_at != null || call.everyone_at != null) return 0
  const payload = await callPayload(db, call)
  if (!payload) return 0
  const { roster, onNow, noResponseMs } = await currentShift(db, now)
  const targets = await listTargets(db, call.id)
  const had = new Set(targets.map((t) => t.user_id))
  for (const r of escalationOrder(roster, onNow?.user_id ?? null)) {
    if (had.has(r.user_id)) continue
    if (!(await stillOpen(db, call.id))) return 0
    // Claim them before pushing, so two runs at once never alert the same person twice.
    const claimed = await db
      .prepare('INSERT OR IGNORE INTO call_targets (call_id, user_id, alerted_at) VALUES (?,?,?)')
      .bind(call.id, r.user_id, now)
      .run()
    if (claimed.meta.changes === 0) continue
    const { sent } = await pushToUser(db, send, r.user_id, payload)
    await addEvent(db, call.id, now, sent > 0 ? 'alerted' : 'no_device', r.user_id, String(sent))
    if (sent > 0) {
      await db.prepare('UPDATE calls SET next_at = ? WHERE id = ? AND accepted_at IS NULL AND closed_at IS NULL').bind(now + noResponseMs, call.id).run()
      return sent
    }
  }
  if (!(await stillOpen(db, call.id))) return 0
  const rejected = new Set((await listTargets(db, call.id)).filter((t) => t.rejected_at != null).map((t) => t.user_id))
  const subs = (await listSubscriptionsForRoles(db, ['operator', 'admin'])).filter((s) => !rejected.has(s.user_id))
  const { sent } = await pushToSubs(db, send, subs, payload)
  if (sent > 0) {
    await db.prepare('UPDATE calls SET everyone_at = ?, next_at = NULL WHERE id = ? AND everyone_at IS NULL').bind(now, call.id).run()
    await addEvent(db, call.id, now, 'everyone', null, roster.some((r) => r.available) ? 'end_of_roster' : 'nobody_on_call')
  } else {
    // Nobody got it. The trip stays unalerted, so the cron raises this call again next minute.
    await db.prepare('UPDATE calls SET next_at = NULL WHERE id = ?').bind(call.id).run()
    console.error('call reached no one', call.id)
  }
  return sent
}

export async function findCallsToEscalate(db: DB, now: number): Promise<Call[]> {
  return (
    await db
      .prepare('SELECT * FROM calls WHERE closed_at IS NULL AND accepted_at IS NULL AND everyone_at IS NULL AND next_at <= ?')
      .bind(now)
      .all<Call>()
  ).results
}

// The no-response time ran out: say who didn't answer, then pass it on.
export async function escalate(db: DB, send: PushSender, call: Call, now: number): Promise<number> {
  const last = (await listTargets(db, call.id)).filter((t) => t.rejected_at == null).at(-1)
  if (last) await addEvent(db, call.id, now, 'no_response', last.user_id)
  return advance(db, send, call, now)
}

export async function acceptCall(db: DB, callId: string, userId: string, now: number): Promise<'accepted' | 'taken' | 'rejected' | 'closed'> {
  // One statement, so the first accept wins however close the second one is.
  const r = await db
    .prepare(
      `UPDATE calls SET accepted_by = ?1, accepted_at = ?2, next_at = NULL
       WHERE id = ?3 AND accepted_at IS NULL AND closed_at IS NULL
         AND NOT EXISTS (SELECT 1 FROM call_targets WHERE call_id = ?3 AND user_id = ?1 AND rejected_at IS NOT NULL)`,
    )
    .bind(userId, now, callId)
    .run()
  if (r.meta.changes > 0) {
    await addEvent(db, callId, now, 'accepted', userId)
    return 'accepted'
  }
  const call = await getCall(db, callId)
  return !call || call.closed_at != null ? 'closed' : call.accepted_at != null ? 'taken' : 'rejected'
}

export async function rejectCall(db: DB, send: PushSender, callId: string, userId: string, now: number): Promise<'rejected' | 'not_yours' | 'closed'> {
  const call = await getCall(db, callId)
  if (!call || call.closed_at != null || call.accepted_at != null) return 'closed'
  const r = await db
    .prepare('UPDATE call_targets SET rejected_at = ? WHERE call_id = ? AND user_id = ? AND rejected_at IS NULL')
    .bind(now, callId, userId)
    .run()
  if (r.meta.changes === 0) return 'not_yours'
  await addEvent(db, callId, now, 'rejected', userId)
  await advance(db, send, call, now)
  return 'rejected'
}

async function closeCall(db: DB, id: string, now: number) {
  const r = await db.prepare('UPDATE calls SET closed_at = ?, next_at = NULL WHERE id = ? AND closed_at IS NULL').bind(now, id).run()
  if (r.meta.changes > 0) await addEvent(db, id, now, 'closed')
}

// Puts what just happened on the trip onto each open call's record. `close` says which calls it ends.
export async function noteOnCalls(
  db: DB, tripId: string, now: number, kind: CallEvent, userId: string | null, close: 'all' | CallKind | null, detail: string | null = null,
) {
  for (const call of await listOpenCalls(db, tripId)) {
    await addEvent(db, call.id, now, kind, userId, detail)
    if (close === 'all' || close === call.kind) await closeCall(db, call.id, now)
  }
}

// A safety net for any path that ends a trip without closing its calls.
export async function closeCallsOfClosedTrips(db: DB, now: number): Promise<number> {
  const rows = (
    await db.prepare("SELECT c.id FROM calls c JOIN trips t ON t.id = c.trip_id WHERE c.closed_at IS NULL AND t.status = 'closed'").all<{ id: string }>()
  ).results
  for (const r of rows) await closeCall(db, r.id, now)
  return rows.length
}

// Who hears the explorer's chat messages. Null when no call is open: every operator and admin, as before.
export async function chatRecipients(db: DB, tripId: string): Promise<string[] | null> {
  const calls = await listOpenCalls(db, tripId)
  if (calls.length === 0) return null
  const ids = new Set<string>()
  for (const c of calls) {
    if (c.accepted_by) {
      ids.add(c.accepted_by)
      continue
    }
    const targets = await listTargets(db, c.id)
    const rejected = new Set(targets.filter((t) => t.rejected_at != null).map((t) => t.user_id))
    if (c.everyone_at != null) {
      const all = (await db.prepare("SELECT id FROM users WHERE role IN ('operator','admin')").all<{ id: string }>()).results
      for (const u of all) if (!rejected.has(u.id)) ids.add(u.id)
    } else {
      for (const t of targets) if (t.rejected_at == null) ids.add(t.user_id)
    }
  }
  return [...ids]
}

type EventRow = { call_id: string; at: number; kind: CallEvent; detail: string | null; name: string | null }

function describe(e: EventRow): string {
  const who = e.name ?? 'Someone'
  switch (e.kind) {
    case 'started': return e.detail === 'help' ? 'Call started: the explorer called for help.' : 'Call started: overdue, and no answer to "Are you okay?".'
    case 'alerted': return `Alert sent to ${who} (${e.detail} ${e.detail === '1' ? 'device' : 'devices'}).`
    case 'no_device': return `${who} has no device that gets alerts.`
    case 'no_response': return `No answer from ${who}.`
    case 'rejected': return `${who} rejected.`
    case 'accepted': return `${who} accepted.`
    case 'everyone': return e.detail === 'nobody_on_call'
      ? 'Nobody is on call. Sent to every operator and admin.'
      : 'Nobody on the roster accepted. Sent to every operator and admin.'
    case 'extended': return `${who} added time.`
    case 'help': return `${who} called for help.`
    case 'help_cancelled': return `${who} cancelled the call for help.`
    case 'back': return `${who} is back safe.`
    case 'siren': return `${who} sounded the siren.`
    case 'closed_trip': return `${who} closed the trip.`
    case 'admin_status': return `${who} set the trip to ${e.detail}.`
    case 'closed': return 'Call closed.'
  }
}

export interface CallView extends Call {
  accepted_name: string | null
  targets: CallTarget[]
  lines: Array<{ at: number; text: string }>
}

// Every call on the trip, newest first, each with its record in time order. Kept after the trip ends.
export async function callsForTrip(db: DB, tripId: string): Promise<CallView[]> {
  const calls = (await db.prepare('SELECT * FROM calls WHERE trip_id = ? ORDER BY started_at DESC, rowid DESC').bind(tripId).all<Call>()).results
  if (calls.length === 0) return []
  const [messages, events] = await Promise.all([
    listMessages(db, tripId),
    db
      .prepare(
        `SELECT e.call_id, e.at, e.kind, e.detail, u.name FROM call_events e LEFT JOIN users u ON u.id = e.user_id
         WHERE e.call_id IN (SELECT id FROM calls WHERE trip_id = ?) ORDER BY e.id`,
      )
      .bind(tripId)
      .all<EventRow>(),
  ])
  return Promise.all(
    calls.map(async (c) => {
      const targets = await listTargets(db, c.id)
      const said = messages
        .filter((m) => m.created_at >= c.started_at && (c.closed_at == null || m.created_at <= c.closed_at))
        .map((m) => ({ at: m.created_at, text: `${m.author_name}: ${m.body || (m.media_type?.startsWith('audio/') ? 'Voice note' : 'Photo')}` }))
      const lines = [...events.results.filter((e) => e.call_id === c.id).map((e) => ({ at: e.at, text: describe(e) })), ...said]
        .sort((a, b) => a.at - b.at)
      const accepted_name = c.accepted_by ? ((await getUserById(db, c.accepted_by))?.name ?? null) : null
      return { ...c, accepted_name, targets, lines }
    }),
  )
}
```

```ts
import { getSetting, prunePositions } from './db'

export const POSITION_RETENTION_MS = 30 * 24 * 60 * 60 * 1000

export async function runCron(env: Env, send: PushSender, now: number) {
  const db = env.DB
  const graceMs = Number(await getSetting(db, 'grace_minutes', '30')) * 60_000
  let prompted = 0
  let alerted = 0
  let helpAlerted = 0
  let escalated = 0

  for (const trip of await findTripsToPrompt(db, now)) {
    try {
      if (!(await markOverdue(db, trip.id, now))) continue
      prompted++
      await pushToUser(db, send, trip.user_id, {
        title: 'Are you okay?',
        body: "You're past your return time. Let us know you're safe, or add more time.",
        url: '/',
        tag: 'overdue',
        requireInteraction: true,
        kind: 'prompt',
      })
    } catch (e) {
      console.error('prompt failed', trip.id, String(e))
    }
  }

  // Overdue and help alerts are calls: they go to the person on shift first and escalate from there.
  // The trip is marked only once a push lands, so a call that reached no one is raised again next minute.
  for (const trip of await findTripsToAlertOperators(db, now, graceMs)) {
    try {
      const r = await raiseCall(db, send, trip.id, 'overdue', now)
      if ((r.sent > 0 || r.accepted) && (await markOperatorsAlerted(db, trip.id, now))) alerted++
    } catch (e) {
      console.error('operator alert failed', trip.id, String(e))
    }
  }

  for (const trip of await findHelpTripsToAlert(db)) {
    try {
      const r = await raiseCall(db, send, trip.id, 'help', now)
      if ((r.sent > 0 || r.accepted) && (await markHelpAlerted(db, trip.id, now))) helpAlerted++
    } catch (e) {
      console.error('help alert failed', trip.id, String(e))
    }
  }

  for (const call of await findCallsToEscalate(db, now)) {
    try {
      await escalate(db, send, call, now)
      escalated++
    } catch (e) {
      console.error('escalation failed', call.id, String(e))
    }
  }

  const callsClosed = await closeCallsOfClosedTrips(db, now)
  const shiftChanged = await syncShift(db, send, now).catch((e) => {
    console.error('shift sync failed', String(e))
    return false
  })
  const pruned = await prunePositions(db, now - POSITION_RETENTION_MS)
  return { prompted, alerted, helpAlerted, escalated, callsClosed, shiftChanged, pruned }
}
```

```ts
async function callAnswer(c: Context<AppEnv>, answer: 'accept' | 'reject') {
  const call = await getCall(c.env.DB, c.req.param('id')!)
  if (!call) return c.json({ error: 'Not found' }, 404)
  const now = Date.now()
  const user = c.var.user!
  const r = answer === 'accept'
    ? await acceptCall(c.env.DB, call.id, user.id, now)
    : await rejectCall(c.env.DB, getSender(c.env), call.id, user.id, now)
  const page = `/board/trips/${call.trip_id}`
  const error = r === 'accepted' || (answer === 'reject' && r === 'rejected') ? null : CALL_ERRORS[r]!
  if (error) return wantsJson(c) ? c.json({ error }, 409) : c.redirect(`${page}?error=${encodeURIComponent(error)}`, 303)
  return done(c, { ok: true }, page)
}
```

```kotlin
@Composable
fun OnCallScreen(go: (Screen) -> Unit) {
    var s by remember { mutableStateOf<JSONObject?>(null) }
    var reload by remember { mutableIntStateOf(0) }
    var adding by remember { mutableStateOf(false) }
    val work = rememberWork()
    val scope = rememberCoroutineScope()
    LaunchedEffect(reload) {
        while (true) {
            withContext(Dispatchers.IO) { runCatching { Api.get("/api/oncall") } }.onSuccess { s = it; onCall = it.getJSONObject("me").optBoolean("on_call") }
            delay(30_000)
        }
    }
    // The reply is the new state. Set it after the IO thread is done, on the main thread.
    fun change(path: String, body: JSONObject) {
        var reply: JSONObject? = null
        work.run(scope, { reply = Api.post(path, body) }) { reply?.let { s = it; onCall = it.getJSONObject("me").optBoolean("on_call") } }
    }
    fun at(ms: Long) = "${android.text.format.DateFormat.format("EEE", ms)} ${hhmm(ms)}"
    OpsPage("On call", go) {
        val st = s ?: run { Text("Loading…", color = Muted); return@OpsPage }
        val admin = Store.role == "admin"
        val now = st.optJSONObject("on_now")
        val me = st.getJSONObject("me")
        ErrorBanner(work.error)
        Card("On call now") {
            if (now == null) Text("Nobody is on call. Alerts go to every operator and admin.", color = Z9)
            else Text(now.optString("name") + (if (st.isNull("until")) ", with nobody else available to take over" else " until ${at(st.getLong("until"))}"),
                color = Z9, fontWeight = FontWeight.Bold)
            st.optJSONObject("next")?.takeIf { !st.isNull("until") }?.let { Text("Next: ${it.optString("name")} from ${at(st.getLong("until"))}", color = ZM) }
            val h = st.optInt("shift_hours")
            Text("Shifts of $h ${if (h == 1) "hour" else "hours"} from 06:00. An alert passes to the next person after ${st.optInt("no_response_minutes")} min with no answer.",
                color = ZM, fontSize = 13.sp)
        }
        if (me.optBoolean("on_roster")) Card("You") {
            val avail = me.optBoolean("available")
            Text(if (avail) "You're available. Alerts can come to you." else "You're unavailable. You're skipped until you switch back.", color = Z9)
            GButton(if (avail) "Make me unavailable" else "Make me available", if (avail) Btn.Outline else Btn.Navy, small = true, enabled = !work.busy) {
                change("/api/oncall/availability", JSONObject().put("available", if (avail) "0" else "1"))
            }
        }
        val roster = st.getJSONArray("roster")
        Card("Order · ${roster.length()}") {
            if (roster.length() == 0) Text("Nobody is on the list yet.", color = ZM)
            for (i in 0 until roster.length()) {
                val r = roster.getJSONObject(i)
                val id = r.getString("user_id")
                Column(verticalArrangement = Arrangement.spacedBy(6.dp)) {
                    Text(r.optString("name"), color = Z9, fontWeight = FontWeight.Bold)
                    Text((if (r.optBoolean("on_now")) "On call now" else if (r.optBoolean("available")) "Available" else "Unavailable") +
                        (if (r.optInt("devices") == 0) " · No device gets alerts" else ""), color = if (r.optInt("devices") == 0) RedInk else ZM, fontSize = 13.sp)
                    if (admin) Row(horizontalArrangement = Arrangement.spacedBy(6.dp)) {
                        GButton("↑", Btn.Outline, small = true, enabled = !work.busy && i > 0, modifier = Modifier.weight(1f)) {
                            change("/api/oncall/move", JSONObject().put("user_id", id).put("dir", "up"))
                        }
                        GButton("↓", Btn.Outline, small = true, enabled = !work.busy && i < roster.length() - 1, modifier = Modifier.weight(1f)) {
                            change("/api/oncall/move", JSONObject().put("user_id", id).put("dir", "down"))
                        }
                        GButton(if (r.optBoolean("available")) "Unavailable" else "Available", Btn.Outline, small = true, enabled = !work.busy, modifier = Modifier.weight(2f)) {
                            change("/api/oncall/availability", JSONObject().put("user_id", id).put("available", if (r.optBoolean("available")) "0" else "1"))
                        }
                        GButton("", Btn.Outline, "x", small = true, enabled = !work.busy, modifier = Modifier.weight(1f)) {
                            change("/api/oncall/remove", JSONObject().put("user_id", id))
                        }
                    }
                }
            }
            val candidates = st.optJSONArray("candidates") ?: JSONArray()
            if (admin && candidates.length() > 0) Box {
                GButton("Add someone", Btn.Outline, "plus", small = true, enabled = !work.busy) { adding = true }
                DropdownMenu(adding, { adding = false }) {
                    for (i in 0 until candidates.length()) {
                        val u = candidates.getJSONObject(i)
                        DropdownMenuItem({ Text(u.optString("name")) }, { adding = false; change("/api/oncall/add", JSONObject().put("user_id", u.getString("user_id"))) })
                    }
                }
            }
        }
    }
}
```
